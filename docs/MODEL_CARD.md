# Model card

| Поле | Значение |
|---|---|
| Задача | Бинарный прогноз `TARGET` Home Credit; ранжирование риска |
| Единица прогноза | Текущая заявка / клиент `SK_ID_CURR` |
| Версия результатов | Kaggle research GPU v1; финальная отправка 27.09.2026 |
| Модель | 75% XGBoost + 25% CatBoost, по два seed на полном train |
| Признаки | 1592 у XGBoost; 1250 у CatBoost |
| Назначение | Исследование, соревнование, учебное портфолио |
| Основная метрика | ROC AUC |
| Kaggle | Public 0.80088; private 0.79968; late submission |
| Локальная оценка | Holdout AUC 0.798087; AP 0.294200; log loss 0.233474 |
| Обучающая выборка final refit | 307 511 размеченных клиентов |
| Тестовый результат | 48 744 вероятности |

## Область применимости

Модель оценена в распределении данных соревнования. Она не валидирована на
новой стране, продукте, временном периоде или современных банковских потоках.
Отсутствует production-сервис и политика принятия решений.

## Что было проверено

ID, согласованность схемы, временная обработка выплат, несколько важных edge cases
очистки, обучение peer-медиан без validation, пять development-фолдов, фиксированная
оценка holdout, одна финальная отправка и независимый пересчёт метрик.

## Что не было проверено

Полная nested CV; out-of-time-обобщение; качество по защищённым группам;
устойчивость к сдвигу распределения; фактическая стоимость ошибок; эксплуатационная
калибровка; устойчивость всех признаков к моменту доступности в реальной системе.
Демографические признаки используются. AUC и графики importance не заменяют эти проверки.

## Интерпретация

Сохранены встроенные feature importance обеих моделей. Шкалы библиотек различаются,
коррелированные признаки могут делить важность. SHAP, причинный анализ и объяснения
отдельных отказов не выполнялись. Оценка AUC не выбирает порог и не обосновывает
автоматическое кредитное решение.

## Обновление

Следующий этап должен начинаться с новых данных/схемы проверки или заранее
зафиксированных development-экспериментов. Просмотренный holdout нельзя бесконечно
использовать для отбора версий и продолжать называть независимым.
