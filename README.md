# Home Credit Default Risk

Решение задачи [Home Credit Default Risk](https://www.kaggle.com/competitions/home-credit-default-risk):
по анкете клиента и его кредитной истории предсказать платёжные затруднения.
Итоговая модель — взвешенный ансамбль XGBoost и CatBoost.

| Оценка | ROC AUC |
|---|---:|
| Kaggle public | **0.80088** |
| Kaggle private | **0.79968** |
| Отложенная выборка | 0.79809 |
| Кросс-валидация, 5 фолдов | 0.79821 |

Результат Kaggle получен поздней отправкой 27 сентября 2026 года.

## Данные

В обучающей выборке 307 511 заявок, в тестовой — 48 744. Положительный класс
составляет 8,07%. Метрика соревнования — ROC AUC.

Основная таблица содержит анкету, доход, сумму кредита и внешние рейтинги.
Дополнительные таблицы описывают предыдущие заявки, кредиты в бюро, остатки
по счетам и платежи. История сначала агрегируется по договору или взносу,
затем по клиенту. Полученные признаки присоединяются к текущей заявке.

При подготовке данных обработаны специальные значения дат и пропуски,
объединены частичные платежи. В расчёт выплаченных сумм входят платежи,
наблюдавшиеся к дате заявки.

## Признаки и модели

Исходный набор из 1250 признаков включает суммы и доли задолженности,
просрочки, использование лимитов, последние операции и изменения во времени.
На нём сравнивались LightGBM, XGBoost и CatBoost.

После первого сравнения добавлены 302 признака условий прошлых кредитов,
плановой нагрузки и истории за 90/730 дней. Ещё 40 признаков описывают
отклонение дохода, кредита и других величин от медиан похожих клиентов.
Эти медианы вычисляются только на обучающей части каждого фолда.

Основные эксперименты на одной валидационной выборке из 49 202 клиентов:

| Модель | Признаки | ROC AUC |
|---|---:|---:|
| LightGBM, исходная модель | 1250 | 0.789813 |
| XGBoost, depth 7 | 1250 | 0.791639 |
| CatBoost, depth 6 | 1250 | 0.788540 |
| XGBoost, depth 7, дополнительные признаки | 1552 | 0.791824 |
| XGBoost, depth 7, сравнение с похожими клиентами | 1592 | 0.791301 |
| XGBoost, depth 4, изменённые параметры | 1592 | **0.792257** |
| LightGBM GBDT, дополнительные признаки | 1592 | 0.791493 |
| LightGBM GOSS, дополнительные признаки | 1592 | 0.790649 |

Лучший одиночный результат дал XGBoost с глубиной 4. Добавление CatBoost
улучшило оценку на кросс-валидации с 0.79737 до 0.79821.
Для финального прогноза выбраны веса **75% XGBoost + 25% CatBoost**.

Самостоятельный вклад новых признаков оказался небольшим: при прежних
параметрах прирост AUC составил 0.00019. В лучшем варианте одновременно
менялись несколько параметров, поэтому вклад глубины и признаков отдельно
не установлен. Подробные сравнения приведены в [отчёте](docs/RESEARCH.md).

## Валидация и финальное обучение

Из размеченных данных выделены 246 009 клиентов для разработки и 61 502
для итоговой проверки. Конфигурации сравнивались внутри первой части.
Затем выбранные модели прошли пять стратифицированных фолдов; веса смеси
подбирались по прогнозам для клиентов, отсутствовавших в обучении соответствующего фолда.
После фиксации весов выполнена оценка отложенной выборки.

Финальные модели обучены на всех метках с двумя seed. XGBoost использует
1500 деревьев, CatBoost — 3284; число деревьев взято из результатов кросс-валидации.
Последний запуск занял 51 минуту на двух Tesla T4, без подготовки данных и ранних экспериментов.

## Запуск

Обзорный ноутбук можно читать прямо на GitHub: выводы ячеек сохранены.
Для полного повторения нужны [данные соревнования](https://www.kaggle.com/competitions/home-credit-default-risk/data).
На Kaggle последовательно выполняются ноутбуки `01_build_features`,
`02_augment_features` и `03_train_gpu`. Входные файлы и настройки каждого
этапа перечислены в [инструкции](docs/REPRODUCIBILITY.md).

Локальная проверка кода и отчёта:

```bash
python -m pip install -r requirements-report.txt
python -m unittest discover -s tests -v
python scripts/check_repository.py
```
